# 👋 Hi, I'm Stanley Amo-Brown Jnr

I'm a **full-stack developer** based in Accra, Ghana 🇬🇭. I build web applications for businesses and organisations across Ghana and West Africa, from the database and API to the interface people actually use.

Most of my client work lives in private repositories, so my contribution graph doesn't tell the whole story. Feel free to explore my portfolio or reach out if you'd like to discuss any of my work.

## 🚀 What I Do
- ⚙️ Build backends and REST APIs with **Laravel** and **Django REST Framework**
- 🌐 Build responsive web apps and dashboards with **React**, **Next.js**, and **Tailwind CSS**
- ⚡ Use **Livewire** and **Alpine.js** for fast, interactive Laravel projects
- 💾 Design relational database schemas and keep queries efficient
- 🧪 Write clean, documented code and collaborate effectively in teams

## 🏗️ Selected Work
- **Nudge (Smart Invoicing & Automated Reminders):** Built a Laravel and Livewire billing platform with scheduled Artisan tasks to automate client payment reminders and invoice tracking.
- **Emergency Resource Coordination API:** Developed a real-time coordination backend using Django, WebSockets, Docker, and AI integration, load-tested for high-concurrency response.
- **Coders Who Travel Inc. Platform:** Architected and rebuilt the non-profit's web platform using React, TypeScript, Tailwind CSS, Brevo API serverless functions, and Paystack donation workflows.
